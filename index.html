Quick start
  1. Tap New project or Open existing.
  2. For a new project, enter the project name, survey type and location.
  3. Confirm the location, then create the project.
  4. Open the field map and add trees, groups, hedges or woodland.
  5. Use Save / sync / backup before closing the app or leaving site.
  6. Use Exports or Share project ZIP when finished.
